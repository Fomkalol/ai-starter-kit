# Шаблон доссье

```markdown
# {Продукт} — product research
Дата: {дата} · Запрос: {что просили} · Гео-фокус: {гео}

## TL;DR (вердикт в 5 строк)
- Имя: {рекомендация или «оставить текущее»}
- Главный риск: {…} (вероятность/цена)
- Главная возможность: {…}
- Next steps: {3 пункта}

## Нейминг (если был)
{таблица по рубрике} + Title/Subtitle с счётчиками + домены/TM/SERP по финалистам

## Конкуренты
{таблица} 
Перенять: … / Никто не делает: …

## Бренд-коллизии и SERP
{кто владеет запросами; тёзки; чей exact-match домен}

## Товарные знаки
{находки по реестрам; свобода классов 9/42; практический риск store-жалоб отдельно от судебного}

## Спрос по гео (если gads был доступен)
{таблица US-first} 

## Голос пользователей (существующий продукт)
{цитаты-кандидаты для соцпруфа; боли из 1★}

## Каннибализация портфеля (если релевантно)
{таблица разведения позиционирования}

## Ограничения данных
{что не удалось проверить: rate-limits, персонализация SERP, закрытые тарифы}

## Next steps
- [ ] руками (ASC/Play/EUIPO/домены): …
- [ ] кодом (лендинг/ASO-тексты): …
```

Правила заполнения: вердикты вместо пересказов; конфликтующие данные — оба значения с источниками; всё недопроверенное — в «Ограничения», не замалчивать.
