# Еженедельные ревью: потрать остаток лимитов с пользой

Лимиты подписки сгорают в конце недели — неиспользованное пропадает. Приём: за день до
сброса запускать большие фоновые прогоны, до которых руками не доходят. Поставь их на
расписание (боковая панель → Routines; в старых версиях — Schedule) или запускай
раз в неделю одной командой.

Ниже — готовые промпты. Копируй, подставляй своё.

## 1. Аудит рабочей системы

> Проведи аудит моей системы работы с AI: прочитай ~/.claude/CLAUDE.md, правила проектов,
> ~/ai-workspace (TASKS.md, память, хендоффы), список скилов и хуков. Найди: устаревшие и
> противоречащие правила, дубли, мёртвый груз, разбухшие файлы памяти, задачи-зомби в
> TASKS.md. Отчёт: топ-5 проблем с конкретным фиксом каждой. Ничего не правь без моего ОК.

## 2. Глубокое ревью главного репо

> Возьми <главный проект> и пройди свежим взглядом ветку main за неделю: git log за 7 дней,
> дифф крупных изменений. Ищи баги, костыли «на потом», дыры безопасности, TODO без задач.
> Найденное — списком «что → чем грозит → фикс», по каждому пункту предложи задачу в бэклог.

Или тяжёлой артиллерией: `sh review/review-deep.sh` на текущей ветке (см. review/README.md).

## 3. Разгрести бэклог

> Открой ~/ai-workspace/products/<продукт>-backlog.md. Проверь каждую задачу: актуальна ли,
> есть ли у неё проблема/результат/приёмка, правильный ли приоритет. Протухшее — в архив,
> размытое — переформулируй, у P1 проверь, что ничего не блокирует. Покажи дифф до/после.

## 4. Конкуренты и рынок за неделю

> Собери, что изменилось за неделю у конкурентов <список>: апдейты, цены, отзывы, новые
> фичи, движение в чартах/выдаче. Сравни с прошлым запуском (файл отчёта прошлой недели —
> приложи), напиши только изменения и что нам с ними делать. Максимум страница.

## 5. Метрики и аномалии

> Вот выгрузки за неделю: <аналитика/продажи/реклама>. Найди аномалии: что выросло или
> упало сильнее ×1.5 к прошлой неделе, где тренд сломался. По каждой аномалии — гипотеза
> причины и как проверить. Без воды, таблицей.

## 6. Чему научиться

> Посмотри changelog Claude Code и новости AI-инструментов за неделю (поиском). Выбери 3
> вещи, которые реально применимы к моему стеку (опиши его из ~/.claude/CLAUDE.md), и по
> каждой покажи: что это, зачем мне, команда/настройка чтобы попробовать за 5 минут.

## Как поставить на расписание

В приложении Claude: боковая панель → Schedule → + New task → Cloud (работает без твоего
компьютера). Частота — еженедельно, за день до сброса лимитов. Результат ждёт утром в чате.
Совет: первую неделю запусти руками и поправь промпт по результату, потом автоматизируй.
