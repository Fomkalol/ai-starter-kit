# Memory index

Индекс памяти: по строке на файл-факт, сами факты — в соседних файлах этой папки.
Агент читает индекс в начале сессии и открывает только нужные файлы.

Правила:
- Один файл — один факт/тема, карточка фактов, не журнал.
- Секреты сюда не писать — только ссылки вида `секрет: ~/.secrets/<файл>`.
- Устарело — обновляй или удаляй, не копи.

Формат файла памяти — `memory-entry-template.md` рядом с этим шаблоном.

## Обо мне
- пример строки: `- [обо-мне](obo-mne.md) — <роль, стек, предпочтения>` (создай файл по memory-entry-template.md)
