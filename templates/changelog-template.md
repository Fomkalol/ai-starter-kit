# <Product> changelog

Короткая хронология заметных изменений продукта. Формат основан на Keep a Changelog; newest first.

Правила:

- `Unreleased` содержит только уже сделанные, но ещё не выпущенные изменения.
- На релизе переносить записи под `## [version] - YYYY-MM-DD`.
- Использовать только `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`.
- Писать результат для пользователя/продукта/эксплуатации, а не список коммитов.
- Для сквозного продукта помечать зону: `[iOS]`, `[Backend]`, `[Analytics]`, `[Ops]`.
- Handoff хранит подробности реализации; backlog — будущие задачи; changelog — только сделанное.
