# AI Starter Kit

Рабочий сетап Claude Code / Claude Desktop, собранный на реальных проектах: хуки-предохранители,
правила для агента, схема хранения ключей, кросс-ревью вторым агентом, система файлов-знаний
(задачи, память, хендоффы) и несколько боевых скилов. Ставится за 10 минут, всё по-русски.

Это не теория — всё отсюда ежедневно работает у автора. Бери целиком или по частям.

## Быстрый старт

```bash
git clone https://github.com/Fomkalol/ai-starter-kit ~/ai-starter-kit
cd ~/ai-starter-kit && sh setup.sh
```

`setup.sh` безопасен: ничего не удаляет, существующие файлы бэкапит, каждое действие печатает.
Можно запускать повторно.

## Ещё проще — пусть поставит сам Claude

Открой Claude Code в терминале и вставь целиком:

```text
Поставь мне рабочий стек для Claude Code по стартер-киту https://github.com/Fomkalol/ai-starter-kit
(гайд команды: https://ai-guide.stepamobile.com/, вкладка «Разработчик»). Сделай по шагам:
1) склонируй кит в ~/ai-starter-kit и прочитай README;
2) запусти установку без вопросов: KIT_POST_HOOKS=y KIT_SUPERPOWERS=y KIT_MARKETINGSKILLS=n sh setup.sh;
3) проверь Codex CLI для кросс-ревью (codex --version); нет — npm i -g @openai/codex;
4) заполни ~/.claude/CLAUDE.md по шаблону rules/CLAUDE.global.md — спроси меня, чем я занимаюсь и на каком стеке;
5) в текущем репозитории создай CLAUDE.md по rules/CLAUDE.project.md;
6) сверь результат с чек-листом «Разработчик» из гайда и скажи, чего не хватает.
Объясняй по ходу, что делаешь и зачем. Перезапуск Claude Code в конце — напомни.
```

Переменные `KIT_*` (y/n) отвечают на вопросы установщика вместо клавиатуры — так его можно
запускать из агента или скриптом.

## Что внутри

| Папка | Что это | Куда ставится |
|---|---|---|
| `hooks/` | 3 хука-предохранителя: блок опасных команд, автоформат, проверка типов | `~/.claude/hooks/` + `settings.json` |
| `rules/` | Шаблоны правил для агента: глобальный и проектный CLAUDE.md | заполняешь под себя |
| `secrets/` | Схема хранения API-ключей вне конфигов + обёртка `run.py` | `~/.secrets/` |
| `review/` | Кросс-ревью диффа вторым агентом: `review.sh` и глубокое `review-deep.sh` | запускается из репо |
| `skills/` | Боевые скилы: `risks` (вскрыть риски до старта), `app-audit` (аудит мобильного приложения), `product-research` (ресёрч ниши/нейминга) | `~/.claude/skills/` |
| `commands/` | Слэш-команды: `/risks`, `/handoff` (передача контекста между сессиями), `/learn` (сохранить уроки сессии в память) | `~/.claude/commands/` |
| `templates/` | Система файлов-знаний: TASKS.md, backlog и changelog продукта, память, хендофф | `~/ai-workspace/` |
| `mcp/` | Проверенные MCP: context7 (свежая дока), playwright (браузер), youtube-transcript | конфиг Claude |
| `weekly/` | 6 готовых еженедельных ревью — сжечь остаток лимитов перед сбросом с пользой | по расписанию |

## Зачем это всё (в двух словах)

- **Хуки** — best-effort предохранитель: ловит типовые опасные команды (`rm -rf /`, force-push,
  `curl | sh` и т.п.) ДО выполнения. Это страховка от типовых промахов, не гарантия. Автоформат
  и проверка типов — опционально: они запускают prettier/tsc открытого проекта, в чужих репо
  это исполнение чужого кода, setup спросит отдельно.
- **Правила (CLAUDE.md)** — агент читает файл в каждой сессии и не переспрашивает одно и то же.
  Самый окупаемый час настройки.
- **Секреты** — ключи лежат в `~/.secrets` (доступ только тебе), в конфигах и чатах не светятся.
- **Кросс-ревью** — перед мержем дифф смотрит второй агент (Codex ревьюит Claude и наоборот).
  Свежий взгляд ловит то, что автор кода не видит. `review-deep.sh` — то же, но с запуском кода.
- **Файлы-знания** — задачи, память и хендоффы живут в файлах, а не в истории чатов:
  любая новая сессия продолжает с того же места.

## Что ещё поставить (не наше, но проверено)

- [superpowers](https://github.com/obra/superpowers) — методология работы с кодинг-агентом
  (планы, TDD, дебаг). `setup.sh` предложит поставить.
- [marketingskills](https://github.com/coreyhaines31/marketingskills) — набор скилов под
  маркетинг/ASO/тексты. Тоже в `setup.sh`.
- MCP `context7` и `playwright` — сниппеты в `mcp/README.md`.

## Зависимости скилов

Скил `app-audit` рассчитан на полный набор: без `mobile-app-design` и части `marketingskills`
(onboarding, paywalls) он делает урезанный аудит — ставь их через setup.sh. `product-research`
аналогично использует competitor-profiling / aso / marketing-psychology из marketingskills.

## Требования

macOS/Linux, git, python3. Для хуков автоформата — prettier/gofmt в проектах (не обязательно).
Claude Code или Claude Desktop; для кросс-ревью — ещё и Codex CLI (`npm i -g @openai/codex`).
